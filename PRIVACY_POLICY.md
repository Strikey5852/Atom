# Atom Discord Bot - Privacy Policy

## 1. Information Collected
Atom collects and stores only the following:
- Server-specific settings (channels configured for QOTD, cat images, etc.)
- Questions added by server users for the QOTD feature

No personal user data (such as DMs, user IDs outside of server context, or messages) is stored.

## 2. Use of Information
The stored information is used solely to provide the bot's functionality:
- Posting Question of the Day (QOTD)
- Sending cat images
- Managing server-specific bot settings

## 3. Sharing of Information
Atom does not share server settings or questions with any third parties. All data remains private to the server and the bot.
